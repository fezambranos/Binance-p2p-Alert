# Registros de decisión de arquitectura (ADR)

Un archivo por decisión, numerado, **inmutable**. Una decisión no se edita: se
sustituye con un ADR nuevo que declara `Sustituye a ADR-nnnn`. El historial de por
qué decidimos algo vale tanto como la decisión.

Formato: Contexto · Decisión · Consecuencias · Alternativas descartadas.

| ADR | Título | Estado |

| [0002](0002-separar-dominio-de-infraestructura.md) | Separar dominio de infraestructura tras interfaces de repositorio | Propuesto |

| [0004](0004-el-sistema-recomienda-no-ejecuta.md) | El sistema recomienda, no ejecuta | Aceptado |
